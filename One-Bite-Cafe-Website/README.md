# One Bite Cafe Website

Clean, zero-dependency static website built with HTML5, CSS3, and Vanilla JavaScript for **One Bite Cafe** (1st Floor, Swastik Arcade, Kusnoor Rd, Kalaburagi, Karnataka 585105).

## Folder Structure
- `index.html` — Main responsive page structure
- `css/style.css` — Custom editorial styling & responsive layout
- `js/script.js` — Live IST opening hours badge, menu filtering, and WhatsApp order bag

## How to Run
Double-click `index.html` to open directly in Google Chrome or deploy the folder straight to Vercel or Cloudflare Pages without any build steps.
